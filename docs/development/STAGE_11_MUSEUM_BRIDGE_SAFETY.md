# 阶段 11：博物馆桥接失败安全契约

更新时间：2026-08-30

## 目标

统一 `/api/museum/query` 的异常边界，确保小智服务端、管理端和日志不会收到
检索依赖或模型供应商的原始异常内容，同时保留可定位问题的稳定错误码。

## 已完成改动

- `backend/api/routes/museum.py`：桥接异常统一经过 Provider 错误分类，响应 `details`
  只返回脱敏错误码和提示；日志只记录请求追踪 ID、异常类型和错误码，不再记录完整堆栈。
- 桥接响应继续保持 `MUSEUM_QUERY_FAILED`、`50001` 和原有 contexts/trace 字段，
  小智插件调用契约不变。
- 新增桥接失败回归用例，验证供应商样式的敏感内容不会出现在响应中。
